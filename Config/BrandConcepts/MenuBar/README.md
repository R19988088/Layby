# Layby 菜单栏品牌图标方案

5 个独立设计方向，未接入应用。当前使用的 MenuBarIcon.svg 未修改。

各图标均为透明背景、纯黑单色矢量，标称尺寸 18×18，viewBox 为 24×24。纯黑填充或描边可用于 template 图像；实际接入时仍需在资源或代码中设置模板渲染。

| 文件 | 方向 | 构想 |
| --- | --- | --- |
| [01-docking-l.svg](01-docking-l.svg) | 停靠的 L | 字母 L 的底部向上挑起，形成开放的停靠位。 |
| [02-notched-block.svg](02-notched-block.svg) | 缺口方块 | 实心方块侧上方切入斜向缺口，用负空间表达入口。 |
| [03-landing-dot.svg](03-landing-dot.svg) | 归位点 | 一颗圆点被不对称的弧线接住，表达轻放和归位。 |
| [04-roadside-bay.svg](04-roadside-bay.svg) | 路旁停靠湾 | 竖向线条向侧面绕出停靠湾，呼应 Layby 的名字。 |
| [05-folded-ribbon.svg](05-folded-ribbon.svg) | 回折带 | 宽带经过斜向回折形成抽象 L，以留白区分折叠的两面。 |

打开 preview.png 或 preview.svg 查看总览，包含放大轮廓和深浅背景下的 16、18、22 px 图标。

这些是待选择和细化的概念草案。
