# 停放区出现动效

窗口从隐藏状态呼出时，玻璃、内容、按钮和阴影整体播放 420 ms 的弹出动画：前约 280 ms 从 38% 等比例放大到 106%，再用约 140 ms 直接缩回 100%。前 60 ms 同步淡入，让较小尺寸阶段更早可见。保留一次恢复，不再多次抖动。

实现位于 `ShelfWindowController.swift` 的 `ShelfSurfaceView.animateAppearance(reduceMotion:)`。Core Animation 仅改变呈现层的缩放与透明度，围绕窗口中心动画；不改变实际窗口尺寸、布局或文件接收区域。横向和纵向采用相同缩放比例，去除挤压、左右抖动及反复回弹。

行为约束：

- 摇晃、修饰键、刘海、快捷键及手动入口统一使用此效果。
- 已可见的窗口再次呼出时不重播。
- 动画开始前完成目标位置和布局；拖入接收无需等待动画结束。
- 关闭、拖动 header、切换展开尺寸时取消未完成的出现动画，立即回到正常比例。
- 开启“减少动态效果”时直接显示，动画过程中开启也会立即停止。
- 只移除本次出现动画，不干扰按钮悬停或蓝色边框呼吸。

动效的整体节奏、每阶段缩放比例及淡入时长均集中在上述方法中，可继续调整手感。实机视觉与真实拖入时机仍需在最新构建中验收。
