# 文件夹浏览

列表和网格中双击已就绪的文件夹可进入，也可使用右键“打开文件夹”。标题显示当前文件夹名称，左上返回按钮逐层返回；回到停放区后，再点击返回才收起为堆叠。浏览期间切换列表/网格会保留所在目录。

目录只加载当前层，文件夹排在前面，同类项目按名称自然排序，默认不显示隐藏项。空目录、读取中和读取失败均有对应提示；读取失败可重试或返回。返回父层时重新选中刚离开的文件夹。

子文件支持单选、Shift/Command 多选、大小摘要、复制、拖出和原生快速查看。目录内容是浏览结果，不会自动添加为停放条目；目录内不提供“从停放区移除”，Delete 不会删除磁盘文件。在目录浏览期间投放新文件会回到停放区根层接收，不会写入当前浏览目录。

## 实现

- `ShelfStore.items` 保存原有停放条目，`visibleItems` 提供当前层的显示、选择、复制和拖出数据；堆叠整体拖出仍使用根层条目。
- `ShelfFolderBrowser` 保存目录页面栈，后台枚举与读取元数据。读取请求使用独立标识；返回、重试、关闭之后的旧结果不会重新出现。
- 子文件的 `FileAccessLease` 持有父文件夹的访问租约，延续沙盒权限及托管临时目录的生命周期。即使关闭停放区，正在进行的预览或导出仍可读到文件，最后一个读取者结束后才回收临时目录。
- 缩略图按可见行请求，切换目录时取消离开页面的未完成请求。

## 验证

单元测试覆盖多层目录、空目录、逐层返回、子文件多选导出、读取失败后重试、迟到读取结果以及托管父目录的访问生命周期。`bash scripts/test-quick-look.sh` 使用真实沙盒窗口验证列表/网格双击进入两层目录、子文件快速查看、实际返回按钮与模式保持。
