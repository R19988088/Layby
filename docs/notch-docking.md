# 刘海下方吸附

拖动顶部提示条，把停放区带到刘海下方附近后松手，即可自动吸附。堆叠、网格、列表及胶囊共用同一个吸附锚点；可见面板顶部距刘海底部 8 pt，水平中心与刘海中心一致。

捕获范围按窗口顶部中心计算：与停靠位置的垂直距离不超过 52 pt，水平距离不超过刘海半宽加 24 pt（最小 80 pt）。仅在真实窗口拖动结束时吸附，不在经过刘海附近时抢走拖动控制权。

固定时需从鼠标按下位置拖出 28 pt 才开始原生窗口移动；普通未固定窗口仍使用 4 pt 阈值。未达到解锁距离的拖动不移动窗口，也不会误触发单击收起/展开。超过阈值后，继续由 WindowServer 跟随原始按下事件拖动；同一次拖离不会再次吸附到刚离开的刘海。吸附和解除固定提供触觉反馈，支持设备上生效。

固定状态下切换视图、收起/展开，以及通过菜单、快捷键或自动拖入再次呼出，都保留刘海锚点。固定于当前会话，关闭停放区会解除固定。拖动被取消或窗口被隐藏时不吸附。显示器参数变化时按显示器标识重新计算位置；原刘海屏移除后解除固定并回到可见屏幕。无实际刘海的屏幕不提供该吸附锚点，既有顶部文件投放入口保持原行为。

拖动文件时，刘海下方的投放提示只显示在没有可见停放区的屏幕上；堆叠、网格、列表和胶囊均计入已有实例，停靠状态不影响判断。窗口跨屏时，两侧可见内容所在的屏幕都隐藏提示；透明阴影不计入。拖动期间新呼出停放区会立即撤下该屏幕已有提示，并阻止尚未执行的悬停激活，其他屏幕不受影响。

实现沿用原生窗口移动与 200 ms 定位动画；开启“减少动态效果”时直接定位。辅助功能提示与 tooltip 会说明已固定和用力拖离操作。

验证：55 项测试、9 个测试套件通过，包含原生窗口吸附、所有内容模式与胶囊、固定时模式切换、强弱拖动区分、取消与重复结束回调、负坐标屏幕和屏幕移除。实际设备上的拖动手感与触觉反馈尚未人工验收。
