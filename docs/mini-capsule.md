# 迷你胶囊

## 操作与布局

- 单击顶部提示条，在松手时收起；胶囊状态下单击同一提示条展开。鼠标移动达到 4 pt 后进入原生窗口拖动，松手不触发切换。提示条支持辅助功能按下操作。
- 移除独立的减号按钮。堆叠右上角保留展开文件列表入口。
- 胶囊可见尺寸为 108 × 20 pt，圆角 10 pt，沿用窗口外侧各 20 pt 的阴影留白。
- 拖动条统一位于顶部中心，命中区域 100 × 16 pt，距玻璃顶部 2 pt；堆叠、网格、列表和胶囊共用同一个原生视图及绘制图层。胶囊不再显示左侧竖条。
- 胶囊仅保留拖动条，移除文件图标、数量、展开箭头以及其他内部状态元素。拖动条中心与胶囊中心重合；单击拖动条恢复后可以查看和拖出文件。
- 胶囊继续支持原生文件拖入，以边框高亮反馈投放目标；文件状态在展开后查看。

## 动画与状态

收起持续 280 ms。玻璃背景、阴影与原文件内容向拖动条的实际中心聚拢：背景缩至胶囊大小，文件和按钮持续缩小至接近一个点，仅在靠近中心的后半段淡出，形成被吸入的效果。通过原生图层坐标转换统一吸入位置，避免 SwiftUI 与 AppKit 坐标翻转导致内容向下消失。拖动条位于独立、未变换的接收层内，始终保留位置、尺寸、悬停状态和图层，不参与缩放或淡入淡出。

展开同样持续 280 ms，反向使用吸入的缩放、位移和透明度轨迹：内容从拖动条中心释放，玻璃与阴影左右对称展开，先快速释放再平稳停下。真实窗口先完成尺寸定位，并在同一个图层事务内安装初始压缩状态；避免原生窗口边框动画造成左右速度不一致或完整内容闪现。切换、关闭和减少动态效果会清理正在执行的展开动画。

拖动条保留同一个 `inVisibleRect` 悬停区域。窗口尺寸切换期间保持悬停状态，布局完成后再按当前鼠标位置校准，忽略旧坐标产生的进入/离开事件；相同目标状态不会重新播放悬停动画，避免列表和网格收起时短暂缩短再伸长。

收起动画结束后只切换真实窗口尺寸并隐藏原内容，不替换拖动条，也不重新创建胶囊内容。动画期间阻止内容操作及投放，避免点击到仍保留原布局的文件行。开启减少动态效果时立即切换。

收起状态独立于 `stack / grid / list`。原 `NSHostingView` 保留，浏览区尺寸保持不变，以保留滚动位置、文件夹路径、选择和文件访问生命周期。胶囊投放始终加入停放区根层，但不重置隐藏的文件夹浏览。胶囊移动后，展开位置跟随其位移，并限制在屏幕可用范围内。

胶囊与展开视图均可[吸附到刘海下方](notch-docking.md)，固定时收起与展开保持同一锚点。

自动拖拽呼出不会把已收起的胶囊移走或展开；手动菜单或快捷键可以恢复。关闭、Esc、⌘W 仍沿用关闭并清空的现有行为。

## 验证

应用构建与签名通过；53 项测试通过。新增验证堆叠、网格、列表切换到胶囊并恢复时，拖动条视图和图层身份一致、屏幕坐标不变，且内容中心和角落在动画各阶段持续靠近拖动条，最终收敛至其中心；胶囊装饰仅在收起完成后出现。展开新增验证三种布局下的容器和内容以拖动条为中心左右对称释放、拖动条原位保留，以及快速切换和关闭的清理。新增悬停回归模拟窗口尺寸切换中的坐标短暂错位及延迟离开事件，验证拖动条不闪动、跟踪区域身份不变且真正离开时反馈正常。其余覆盖单击与拖动区分、原始鼠标按下事件交接、顶部中心收缩、动画中恢复、文件夹状态保留、原生投放回调、窗口移动和关闭清理。

当前命令行工具链的增量构建需要显式载入 Testing 宏：

```sh
CLANG_MODULE_CACHE_PATH="$PWD/build/modules" \
SWIFTPM_MODULECACHE_OVERRIDE="$PWD/build/modules" \
swift test --disable-sandbox --scratch-path build/swift-tests \
  -Xswiftc -load-plugin-library \
  -Xswiftc /Library/Developer/CommandLineTools/usr/lib/swift/host/plugins/testing/libTestingMacros.dylib
```
