# 设置面板与应用语言

## 入口与布局

菜单栏图标下拉中的“设置…”打开独立设置窗口，也保留 ⌘, 快捷入口。窗口复用，默认 760 × 600 pt，可调整尺寸，最小 700 × 520 pt。左侧 180 pt 原生侧边导航包含“功能设置”和“通用设置”，右侧为分组表单。

功能设置可开关四种呼出方式：摇晃文件、修饰键拖拽、刘海投放、全局快捷键。保留摇晃幅度、修饰键选择、快捷键录制、辅助功能访问说明和排除应用设置。无刘海屏幕顶部入口作为刘海方式的附属选项，主开关关闭时一起禁用。

## 语言

通用设置提供“跟随系统 / English / 中文”，默认跟随系统；选择保存到 `UserDefaults.language`，立即生效并跨启动保留。

`AppLocalization.swift` 集中管理文字和格式化。跟随系统时按系统偏好语言顺序选择支持的中文或英文，未匹配时回退英文；中文变体使用简体中文界面。设置窗口、菜单栏、停放区、刘海提示、快捷键显示和辅助功能标签同步更新，不重启或清空文件列表。实际文件名保持原样。切换语言时清除已显示的临时操作提示，避免残留旧语言。

AppKit 菜单复用同一个 `NSStatusItem`，语言刷新不会新增菜单栏图标。系统语言通知会重新解析“跟随系统”；macOS 自身要求注销或重启的系统语言改动仍遵循系统行为。

## Dock 行为

应用启动维持 `.accessory` 激活策略；打开设置前也明确保证 `.accessory`。设置通过普通可聚焦窗口显示，不切换为 `.regular`。Xcode 和本地构建均保留 `LSUIElement = true`，打开、关闭或重新打开设置不应让应用进入 Dock。

## 验证范围

新增测试覆盖语言和四种入口开关持久化、无效语言配置回退、系统偏好匹配、显式语言覆盖、即时中英文文案及快捷键标签更新。真实 Dock 显隐、侧边栏视觉和四种入口的鼠标操作仍需实机验收。

macOS 27 本地构建与签名、Xcode Debug 构建及 25 项测试通过；两份产物的 `LSUIElement` 均验证为 true。Xcode 自带 26.5 SDK，仍有目标系统版本 27.0 的已知环境警告。
