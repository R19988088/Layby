# 紧凑窗口与实心按钮

日期：2026-09-12。延续文件堆叠与展开浏览，调整窗口比例、顶部拖动条和按钮样式。

## 尺寸

| 项目 | 当前尺寸 |
| --- | --- |
| 堆叠内容 | 260 × 280 pt |
| 展开内容 | 500 × 360 pt |
| 圆角 | 26 pt |
| 主要圆形按钮 | 30 × 30 pt |
| 网格/列表切换按钮 | 26 × 26 pt |
| 底部数量胶囊 | 高 32 pt |
| 网格卡片 / 列表行 | 高 146 / 54 pt |

窗口四周仍有各 20 pt 的透明阴影区域；文件堆叠会根据剩余空间自动缩放。展开浏览保持三列网格，空间较小时自动减少列数。

## 顶部拖动与空状态

拖动条从按钮行中分离，放入独立的 16 pt 高顶部命中区域。内容顶部留白为 2 pt，横条上沿距玻璃可见上沿约 8.5 pt。横条厚 3 pt，默认宽约 26 pt，悬停展开到 80 pt。继续使用原生按住拖动窗口与减少动态效果适配。

移除空状态的内部底板和虚线，保留“拖入文件或文件夹”提示；拖入时用整体玻璃染色、外缘实线和提示文字反馈。

## 按钮

所有停放区内的操作按钮统一使用 `ShelfSolidButtonStyle`，以不透明灰色填充，分别适配深浅模式。默认、选中、悬停、按下及禁用状态使用不同色阶。悬停以 120 ms 改变明暗，不缩放按钮或改变命中范围；开启“减少动态效果”时立即切换，禁用按钮不响应悬停高亮。

文件堆叠的整体拖出、网格/列表的单项拖出、返回和关闭清空逻辑保持原有行为。

## 验证

macOS 27 命令行构建及签名、Xcode Debug 构建、现有 21 项回归测试通过。悬停状态直接存储 SwiftUI `State` DynamicProperty，兼容当前命令行 SDK 缺少新版 `State` 宏插件的环境。未新增仅验证样式常量的测试。

本轮未完成实机视觉和悬停验收。需检查深浅模式下的实心按钮、禁用按钮不高亮、指示条上沿位置，以及缩小后网格和文件堆叠仍可正常拖出。
