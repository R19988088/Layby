- 已有内容仍可选择、拖出、移除和清空；设置通过菜单栏访问。

## Header 交互

`ShelfHeaderDragHandle` 内的原生 `HeaderDragView` 负责悬停和窗口移动。

| 状态 | 表现 |
| --- | --- |
| 普通状态 | 居中 32 pt 短横条 |
| 鼠标进入 | 约 180 ms 展开至 100 pt，提高对比度，显示张开的手形光标 |
| 按住 header | 显示抓握光标，通过 `NSWindow.performDrag(with:)` 移动窗口；支持按住后再移动 |
| 鼠标离开 | 约 140 ms 收回短横条 |
| 减少动态效果 | 跳过动画，直接应用目标状态 |

动画仅修改独立图层的水平缩放和透明度，header 的命中范围不随动画改变。新的悬停状态从当前呈现状态衔接，不需要等待上一段动画结束。

窗口拖动使用原始 mouse-down 事件交给 Window Server；该 API 立即返回且可能不回传 mouse-up，因此只在本次拖动期间以 30 Hz 检查按钮释放，结束后停止计时器。关闭整个背景的自动窗口拖动，仅 header 可移动窗口。

用户开始拖动 header 时取消空面板的自动隐藏，防止手动移动过程中窗口消失。原生窗口行为依据 [Apple performDrag(with:) 文档](https://developer.apple.com/documentation/appkit/nswindow/performdrag%28with%3A%29?changes=_1)。
